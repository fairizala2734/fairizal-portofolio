# Fairizal Arifianto Portfolio

Static portfolio site ready for Vercel.

## Pages

- `/` — homepage
- `/projects` — all projects
- `/project-stunting` — Stunting Classification Pipeline case study

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Import the repository in Vercel and deploy with the default settings.
3. In Vercel, open **Settings → Domains** and add the custom domain after purchasing it.
4. Follow the DNS record instructions displayed by Vercel at your domain registrar.

The site has no build step and is served as static HTML, CSS, JavaScript, and local assets.
